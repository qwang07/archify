# Archify plugin

Unofficial packaging of [Archify](https://github.com/tt-a1i/archify) for Codex and Claude Code.

The complete upstream skill is copied unchanged into `skills/archify/`.
See [upstream.json](upstream.json) for the exact upstream commit and tree.
No credentials are needed. Node.js 18+ is required by Archify.

Install from [qwang07/plugins](https://github.com/qwang07/plugins).
Packaging and the daily sync workflow live on the [packaging branch](https://github.com/qwang07/archify/tree/packaging/.github/plugin).
